# השוואת סל קניות

דף חי: https://claude.ai/artifact/FAQj9WNYdWvjgC2FinEH4o

השוואת מחירים בין 6 רשתות (שופרסל, רמי לוי, קרפור, יוחננוף, אושר עד, טיב טעם) ל-60 מוצרים נפוצים.
מקור: Apify, הכלי swerve/supermarket-prices, שקורא את קובצי המחירים שהרשתות מפרסמות לפי חוק שקיפות המחירים.
מחירי מדף בסניף פיזי (001, או 002 בקרפור ובטיב טעם), לא אונליין, ללא מבצעים.

## הקבצים

| קובץ | מה הוא עושה |
|---|---|
| `products.json` | רשימת 60 המוצרים, הקטגוריה ומילות החיפוש |
| `spec.mjs` | כללי ההשוואה לכל מוצר: גודל יעד, ק"ג, מילים לסינון |
| `fetch.mjs` | משיכה ראשונה מ-Apify → `raw_prices.json` |
| `fetch_extra.mjs` | השלמה לפי ברקוד מדויק וחיפושי ירקות → `raw_extra.json` |
| `fetch_gaps.mjs` | השלמת חסרים מתוך הסניף → `raw_gaps.json` |
| `analyze.mjs` | בחירת הפריט בכל רשת, נרמול גדלים, השלמה לפי סדר יוקר → `basket.json` |
| `template.html` | עיצוב הדף והלוגיקה של הסל |
| `build.mjs` | כמויות ברירת המחדל, ובניית `basket-compare.html` |

## הרצה

מפתח ה-API של Apify שמור במשתנה הסביבה `APIFY_TOKEN` של המשתמש ב-Windows (לא בקבצים).
כל משיכה עולה כסף מהקרדיט של Apify. בתוכנית החינמית יש $5 לחודש.

```
node fetch.mjs
node fetch_extra.mjs
node fetch_gaps.mjs
node analyze.mjs
node build.mjs
```

לבנייה מחדש של הדף בלי משיכה חדשה (בחינם): `node analyze.mjs` ואז `node build.mjs`.
אחרי זה מבקשים מ-Claude לפרסם מחדש את `basket-compare.html` לאותו קישור.

## לחודש הבא

- להוסיף מבצעים (מצב promoSnapshot, מאותם סניפים). קודם בדיקה על רשת אחת כדי למדוד עלות.
- להשתמש רק במבצעים עם promoPriceTrusted, ולהציג מחיר עם ובלי מבצעים, עם מתג למבצעי מועדון.
- רענון קבוע: מומלץ פעמיים בשבוע (ראשון וחמישי).
